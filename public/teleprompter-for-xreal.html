FAQ

XREAL teleprompter questions.

How does Spector appear on XREAL?

XREAL acts as the display for your connected phone or computer. Open Spector in that device's browser, start the player, and mirror the screen into the glasses.

Which XREAL models work?

Any XREAL model that can show your phone or computer screen should be able to display Spector. The current beta focuses on Air 2, One, and Pro setups so we can document the details accurately.

Do I have to install anything?

No app store is required. Open Spector in a browser and optionally install the PWA for offline rehearsal. The core is free and open source.

Is it really free?

Yes. The complete product available today is free, with no watermark or account requirement. Try it now.
